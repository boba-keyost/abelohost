## Тестовое задание

### Зависимости

* docker
* make (опционально для запуска скриптов из Makefile)

### Запуск

* ```# make run``` - Соберёт и запустит 3 контейнера: `mysql`, `migrations` и `app`
* ```# make run-infra``` - Соберёт контейнер с базой: `mysql`
* ```# make run-migrate-up``` - Соберёт контейнер с миграциями базы данных: `migrations`
* ```# make run-app``` - Соберёт контейнер с приложением в production режиме: `app`
* ```# make run-app-debug``` - Соберёт контейнер с приложением в development режиме: `app`

### Приложение

Дополнительно можно редактировать .env файлы в директории /app/ для внесения правок в конфиг приложения

Приложение доступно по адресу http://127.0.0.1:8080/

Страницы:

* http://127.0.0.1:8080/ - Главная со списком категорий
* http://127.0.0.1:8080/category/{category_id} - Страница категории с пагинацией и сортировкой
    * Сортировка доступна по нескольким полям. Для поля сброса нужно 2 раза перейти по соответствующей ссылке
    * Пагинация задаётся через offset
* http://127.0.0.1:8080/post/{post_id} - Страница с постом.

Если в адресе есть параметр `?json=` или в заголовке запроса указан тип `Content-Type: application/json` - то содержимое
страницы будет выведено в формате JSON
